# ADR-006: Optional ONNX Dependencies via Extras Group

**Date:** 2026-02-04
**Status:** Accepted
**Decider:** thatAverageGuy

## Context

ONNX export requires `onnx` and `onnxruntime` packages. These add ~300MB to
the install. Most users don't need ONNX export. The base package must stay
lightweight (only `torch` required).

## Decision

`onnx` and `onnxruntime` are optional deps under `[onnx]` extras group:

```bash
pip install mono-quant          # base only
pip install mono-quant[onnx]    # base + onnx/onnxruntime
```

Lazy imports inside `export_to_onnx()`:
```python
def export_to_onnx(...):
    try:
        import onnx
        import onnxruntime
    except ImportError:
        raise ImportError(
            "ONNX export requires: pip install mono-quant[onnx]"
        )
```

## Consequences

- Base `import mono_quant` never imports onnx (no startup cost)
- Users get a clear error message if they forget `[onnx]`
- Pattern extends to future formats: `[gguf]`, `[gptq]`, etc.
- CI/CD installs `mono-quant[onnx]` to run ONNX tests
